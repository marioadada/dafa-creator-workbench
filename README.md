# 大发创作工作台 · dafa-creator-workbench

> 一个单文件、零部署的「个人创作作战仪表盘」，由 AI Agent 每日自动喂料真实热点情报。
> 2026 1024 程序员节展示作品。

## 这是什么

把内容创作者每天要盯的选题情报、创作素材、打卡、复盘，全部集成进一个**双击即开**的 HTML 页面。背后的 AI 流水线每天定时联网抓取 6 大领域真实信息，结构化写回页面，并保留历史快照可回看。

人类只负责看和用；从找数据、改页面到故障恢复，全程 AI Agent 完成。

## 功能

页面 11 个模块：AI 编程情报、OPC 一人公司案例、小说爆款赛道、热点视频二创、财经快讯（A 股红涨绿跌）、AI 编程痛点教程、英语跟练、运动跟练、每日计划、备忘录、内容复盘。

前 8 个情报模块由定时自动化每天 09:00 自动更新；任务 / 备忘 / 打卡 / 复盘存浏览器 `localStorage`，随写随存。

## 亮点

- **情报可追溯**：每条数据带真实原文链接，信源分 A 官方 / B 权威 / C 二手，核心事实 ≥2 独立源交叉验证。
- **数据双轨隔离**：联网情报（`DATA` 对象）与个人数据（`localStorage` 7 个键）彻底解耦——刷新热点永不清掉你的打卡进度。
- **历史快照回看**：每次刷新前旧数据自动存档（最多 30 天），可回看任意日期热点，并算新增 / 升温 / 降温。
- **自愈式写盘**：统一脚本写盘前做 7 项校验（JSON 解析、逻辑区逐字节一致、localStorage 键不变、英语课程不动、语法检查等），任一失败立即中止；跑前自动带时间戳备份。

## 运行

```bash
# 生成当日数据（联网抓取后构造，带 schema 断言）
python3 scripts/build_refresh_data_20261025.py

# 写回 HTML（历史快照 + 七项校验 + 更新 lastUpdate）
python3 scripts/daily_refresh_patch.py \
  --html dafa-creator-workbench.html \
  --data new_data_20261025.json
```

依赖：Python 3 标准库即可，无需第三方包。

## 文件结构

```
dafa-creator-workbench.html      # 工作台本体（单文件，~1.1MB）
scripts/
  daily_refresh_patch.py         # 核心写回 + 校验脚本
  build_refresh_data_*.py        # 每日数据构造（schema 断言）
  build_english_curriculum.py    # 英语课程生成器
  incr_refresh_patch.py          # 同日增量补丁
```

> 个人数据（任务 / 备忘 / 打卡）存于浏览器本地，不在仓库内，公开仓库不会泄露私人内容。
